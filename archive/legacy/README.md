# Archived experiment scripts

These files are retained as historical references and are not part of the supported pipeline:

- `prepare_dataset.py` is an earlier teacher-trace generator. Use `data_generation/generate_data.py` for the current generation flow.
- `evaluate_sft.py` and `evaluate_grpo.py` are standalone evaluators. Use `scripts/evaluate_all.py` for new evaluations and comparable result files.

The legacy scripts may use older prompts, settings, or file paths. Their results should not be mixed with the current pipeline without checking those differences.
